Organization Admins can access the IRB Library from organization settings. It documents the generic
placeholders, imagery categories, and recruiting channels used across recruitment content, for use when
preparing materials for IRB review. Only Organization Admins can view or download items from the library,
the same access gate used for the Team settings page.

<Note>
  Requirements vary by IRB. Confirm directly with the study's IRB of record what needs review before
  launching. Any alterations to this library only apply to new studies, and users are notified when that
  happens. To use your own materials instead, email them along with your organization's sharing code to
  irb@jaspari.com before launching your studies.
</Note>

## Text placeholders

Recruitment content uses a fixed set of placeholders rather than free text, so the same reviewed language
is reused consistently across a study. These cover the study name, condition name, and site location as
they appear on the study record; the eligibility criteria bullets, pulled from the study's eligibility
summary; and two controlled-vocabulary fields, compensation phrasing and the call-to-action wording, each
chosen from a fixed list of pre-approved options rather than written freely per study.

## Imagery categories

Photos used in recruitment materials are drawn from five categories: outdoor lifestyle, home lifestyle,
neutral/cartoonish (no people, icon-only), age-matched to the study's eligible range, and group or family
shots. Within every category, the people shown vary in race, ethnicity, gender presentation, age, body
type, and setting, so no single demographic is used exclusively or disproportionately. Imagery is never
shown depicting a clinical setting, medication use, a procedure, or any particular reaction to the study
itself. The photo pool is added to on an ongoing basis, and each new photo is checked against its
category's description before use.

## Recruiting channels

The library also documents every channel recruitment materials can run through, so admins know what a
given piece of content may be used for before it's approved. This spans offline and partner channels
(provider and pharmacy referrals, health system partnerships), owned properties (Jaspari.com), and a long
list of paid and organic social/ad platforms (Facebook, Instagram, Reddit, TikTok, YouTube, Google Ads,
and others), plus channels like affiliate creators, sponsored blog content, and classifieds. Each channel
entry distinguishes paid vs. organic use where that distinction applies, since IRBs often care about that
split.

## Downloading examples

Each text placeholder and imagery category has an example file that can be downloaded from the library.
Downloads are proxied through the app's own API rather than linked directly to the CDN, so the file saves
to disk instead of opening in the browser.
